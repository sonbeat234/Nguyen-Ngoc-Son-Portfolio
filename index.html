      02 / The IC design flow

      From specification to silicon.

      Seven stages every digital chip passes through on its way to the fab.

      01 / 07 Specification

      1. Stage 01

        Specification

        Every chip starts as a contract: what it must do, how fast it must run, how much power it may burn and how much silicon it may occupy.

        Function · Performance · Power · Area

      2. Stage 02

        Architecture

        The design is partitioned into blocks — control, datapath, memory, interfaces — and the trade-offs between them are settled before any logic is written.

        Partitioning · Interfaces · Trade-offs

      3. Stage 03

        RTL design

        Behaviour is described at register-transfer level in Verilog, SystemVerilog or VHDL — hardware written as code, one clock edge at a time.

        Verilog · SystemVerilog · VHDL

        module counter #(parameter W = 4) (
  input  logic         clk, rst_n, en,
  output logic [W-1:0] q
);
  always_ff @(posedge clk or negedge rst_n)
    if (!rst_n)  q <= '0;
    else if (en) q <= q + 1'b1;
endmodule

      4. Stage 04

        Functional verification

        Testbenches, assertions and coverage try to break the design in simulation, long before silicon gets the chance.

        Testbench · Assertions · Coverage · UVM

      5. Stage 05

        Logic synthesis

        RTL is mapped onto a standard-cell library and optimised against timing constraints, producing a gate-level netlist.

        Standard cells · SDC · Netlist

      6. Stage 06

        Physical design

        Floorplanning, placement, clock-tree synthesis and routing turn the netlist into polygons on stacked metal layers.

        Floorplan · Placement · CTS · Routing

      7. Stage 07

        Signoff & tape-out

        Static timing, DRC, LVS and power checks must all come back clean. Then the GDSII layout is released to the fab.

        STA · DRC · LVS · GDSII
